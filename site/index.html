Honest reading of the numbers

Few pneumonia cases are missed (recall 0.97), but specificity is 0.67, so some normal X-rays are flagged. Test accuracy is 85.9%. Grad-CAM shows some heat on image borders and the “R” marker, so the model can pick up shortcuts. That is why PneumoAI supports doctors and never replaces them.

Data: Kaggle chest-xray-pneumonia, 5,216 training images (80/20 split), 624 test images.
